# 04. Comentarios en el Código

PHP admite comentarios con sintaxis heredada de C, C++ y Unix shell:

```php
<?php
// Comentario de una sola línea (estilo C++)

# Comentario de una sola línea (estilo Shell/Perl)

/*
  Comentario multilínea (estilo C)
  Útil para documentar bloques
  o desactivar secciones enteras.
*/

// Los comentarios de una línea solo finalizan al saltar de línea o al cerrar PHP:
?>
```
